# Highlight

Cross-reference highlighting: a dotted underline marks a term; hovering or focusing it fills every occurrence on the page with `highlight`, clicking or Enter pins it, and Escape releases.

**Use** for the terms people trace across panels: names, environments, identifiers. Mark every occurrence, or the feature lies. Pair it once per page with `WKX.Hint`, the pale chip that explains the gesture.

**Consumer provides** the visible text as children and a `term` key when several spellings should light together.

**Don't** mark ordinary words, or use `highlight` for anything but this.
