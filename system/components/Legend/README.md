# Legend

A key strip under the page head that teaches the status lights once: light, the app's word for the state, and what it asks of the reader.

**Consumer provides** `items` (`{status, term, meaning}`), with `term` in the app's own vocabulary; the system fixes only the light for each status (`good`, `caution`, `danger`, `off`).

**Use** one per page, near the top, whenever the page shows more than one status.
