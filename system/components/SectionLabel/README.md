# SectionLabel

The signature section head: a short rule, an uppercase condensed label in `ink-muted`, and a rule running to the edge.

**Use** it to open every panel and page section. Pass `code` for a machine identifier (a path, a resource name), set in mono `ink` ahead of the label; the two are joined by ` · `.

**Consumer provides** the label as children, optionally `code`.

**Don't** use it for headings inside running prose, or stack two in a row.
